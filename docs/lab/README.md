# The Garment Lab — commerce for BREAKTHYRULE

Branch: `claude/garment-lab` (built on `claude/gifted-edison-gyg0ql`). Nothing here is live until the activation
checklist at the bottom is complete.

## What it does

| Page | URL | What it is |
| --- | --- | --- |
| The Garment Lab | `/lab` | Six-step builder (construction → garment → size & fit → colour → artwork → review), the Altar of Chance (Random Art / Total Chaos), The Relic Box, The Trinity, and a filterable catalog of every offering |
| Cart | drawer on every page | Edit, quantity, remove, note, saved in the browser; checkout button |
| Order page | `/lab-order?ref=…&key=…` | The customer's private order page: payment status, pieces, totals, production timeline, tracking |
| Studio | `/lab-admin` | Staff dashboard: orders, production status, notes, assignee, progress photos, shipping, refunds/cancel, Relic Box contents, stock, capacity, archive, waitlist, launch settings, staff |
| The Reliquary | `/reliquary` | Published one-of-one garments |
| Garment passport | `/passport?id=BTR-P…` | One piece's public record with a QR code back to the page |
| Test gateway | `/lab-testpay` | Local/test only: stands in for Stripe so the flow can be tried with no money moving |

Entrances: the **Lab** tab in the site header, the Garment Lab band on the home page, the footer, and a
**GARMENT LAB** link in the 3D showroom's header. (A walk-in portal inside the 3D world was not built; the header
link keeps checkout one click away without touching the scene.)

## Prices (exact, in `labkit/catalog.mjs`)

The Canvas — T-shirt $60 · Hoodie $80 · Sweatpants $80 · Crewneck $80 · Shorts $80
Cut & Sew — T-shirt $80 · Heavyweight hoodie $180 · Sweatpants $180 · Crewneck $150 · Long sleeve / thermal $120 · Shorts $150

All money is integer cents. The browser shows prices from the same catalog, but **the server re-prices every
checkout from the catalog and ignores anything the browser sends**.

## Decisions (made so the build could finish; all easy to change)

- **One package:** `@netlify/blobs` (approved) for storage on Netlify. Stripe is called over its REST API; QR codes,
  passwords and tokens use Node's built-in crypto.
- **Previews vs production:** production deploys use the Blobs store `garment-lab`; every other deploy (drafts,
  previews) uses `garment-lab-preview`, so test orders never mix with real ones. Previews without Stripe keys run the
  test gateway and keep their own random session secret; production never enables the gateway.
- **Function bundling:** `tools/deploy-netlify-draft.sh` bundles `netlify/functions/lab.mjs` with esbuild (so
  `@netlify/blobs` is inside) before uploading — Netlify's own CLI bundler left the package out.
- **Stripe Checkout** handles cards, shipping-address collection, shipping rates and tax. Card details never touch
  our servers. Orders become paid only from a **signature-verified webhook**; each event is processed once.
- **Reservations**: stock (Trinity, Relic Box) and capacity (Canvas, Cut & Sew) are held for 30 minutes while the
  customer pays (the Stripe session expires at the same time), committed on payment, released on failure/expiry.
  Writes are conditional (etags), so concurrent checkouts cannot oversell (tested with 10 buyers for 3 units).
- **Nothing is purchasable until you enter real numbers.** Stock and capacity start at zero; lead times are shown
  only when set. No size measurements are published (`SIZE_CHART = null`); the Lab says so.
- **The Canvas is made to order** (capacity slots per garment), Cut & Sew is a commission (capacity slots, one per
  line), the Trinity and the Relic Box are ready-made stock (per size).
- **Total Chaos** keeps construction and size (the customer's price class and essentials) and redraws garment,
  colour (black/white/random — never a paid custom colour), fit and artwork. The price shown is the price charged.
- **Random art references curated Break Thy Rule graphics** and producible treatments only; it never generates an
  image. The seed is stored; the server re-derives the draw from it.
- **Previews are labelled concept drawings.** True 3D previews need blank garment models — the Ghost Studio blanks
  at ghost.thecreatingco.com/shaka (tee, hoodie, crewneck, pants) can be dropped in once approved.
- **Customer accounts**: none. Each order has a private link with a secret key (only its hash is stored). Order
  history per customer can come with Circle SSO or a later accounts system.
- **Staff**: owner (everything) and artist (production, notes, photos, archive). Tokens last 12 hours; sign-in
  locks for 15 minutes after 8 failures.

## Environment variables

| Variable | Needed for | Notes |
| --- | --- | --- |
| `STRIPE_SECRET_KEY` | checkout | `sk_test_…` for test mode, `sk_live_…` for real money |
| `STRIPE_WEBHOOK_SECRET` | checkout | Signing secret of the webhook endpoint `https://<site>/api/lab/stripe-webhook` |
| `LAB_SESSION_SECRET` | studio sign-in | Random string, 32+ characters |
| `LAB_BOOTSTRAP_OWNER` | first studio login on Netlify | `email:hash` from `node tools/lab/hash-password.mjs you@example.com` |
| `LAB_PUBLIC_URL` | recommended | e.g. `https://breakthyrule-eden-showroom.netlify.app` (return links) |
| `LAB_SHIP_COUNTRIES` | optional | Comma list for Stripe address collection, default `US` |
| `LAB_STRIPE_SHIPPING_RATES` | shipping | Comma list of Stripe shipping-rate IDs |
| `LAB_STRIPE_AUTOMATIC_TAX` | tax | `true` once Stripe Tax is set up |
| `LAB_ALLOW_LIVE` | live switch | Must be `true` (with an `sk_live_` key) before real-money checkout opens |
| `LAB_STORE` | optional | `blobs` (Netlify default), `file` (local default), `memory` |
| `LAB_PAYMENT_PROVIDER`, `LAB_ALLOW_TEST_GATEWAY` | local testing | `test-gateway` + `true` enables `/lab-testpay`; refused when `CONTEXT=production` or a Stripe key is set |

## Data (Netlify Blobs store `garment-lab`, or `server/data/lab/` locally — git-ignored)

`settings`, `inventory`, `capacity`, `orders/<id>`, `events/<stripe event id>`, `checkout-requests/<key>`,
`staff/<email>`, `login-failures/<hash>`, `waitlist/<hash>`, `uploads/<id>`, `archive/<passport id>`.
No migrations are needed: documents are created on first write. Nothing touches existing site data.

## The preview test store

The draft previews share the `garment-lab-preview` store. It holds placeholder TEST stock and capacity and a test
studio account (`owner@lab.test`), loaded with `netlify blobs:set garment-lab-preview …`. Wipe or replace it any time;
it is never read by production.

## Running it locally

```
node tools/lab/create-staff.mjs you@example.com owner          # studio login (local store)
node tools/lab/seed-local-test.mjs                             # placeholder TEST stock — local only
LAB_PAYMENT_PROVIDER=test-gateway LAB_ALLOW_TEST_GATEWAY=true LAB_SESSION_SECRET=<32+ chars> node server/eden-server.mjs
node --test server/lab/lab.test.mjs                            # automated tests
```

## Activation checklist (live checkout)

1. ~~Install `@netlify/blobs`~~ — done. The production deploy script must bundle the function the same way as
   `tools/deploy-netlify-draft.sh` does.
2. In Stripe: get test keys; add the webhook endpoint `/api/lab/stripe-webhook` for `checkout.session.completed`,
   `checkout.session.async_payment_succeeded`, `checkout.session.async_payment_failed`, `checkout.session.expired`,
   `charge.refunded`; create shipping rates; set up Stripe Tax if you collect tax.
3. Set the environment variables above on the Netlify site (test keys first). Deploy a preview and run a test
   order end to end with a Stripe test card.
4. In the studio: enter real stock for the Trinity and the Relic Box, capacity (and lead times if you want them
   shown) for each Canvas and Cut & Sew piece.
5. Measure the real blanks and patterns; add `SIZE_CHART` in `labkit/catalog.mjs`; tick "Size charts published".
6. Write and publish the Relic Box policies (guaranteed contents, condition, sizing, fulfilment) in the studio.
7. Tick "Shipping and tax configured" once Stripe rates/tax are set.
8. Switch to `sk_live_…` keys and a live webhook secret, set `LAB_ALLOW_LIVE=true`, deploy, place one real order
   and refund it.
