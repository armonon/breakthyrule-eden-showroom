# Known gaps at handoff

These are machine-bound gaps, not missing design work.

1. The handoff environment cannot access the user’s current local repository or unpushed branch.
2. Pinned three.js and glTF Transform packages have not been downloaded into this folder.
3. KTX-Software has not been installed into this folder.
4. Blender has not been run here, so the fifteen final sector GLBs are not included.
5. The previously approved tree source is not bundled; the agent must locate it locally.
6. No M4 WebGPU/WebGL2 benchmark has been run.
7. No current-garden comparison screenshot has been captured.
8. The final browser-versus-UE5 verdict remains intentionally blank until measured.

The source runtime has a procedural proxy for both architecture and vegetation so integration can begin before these gaps are closed.
