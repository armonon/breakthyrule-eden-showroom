Showroom changes (tools/build-human-assets.py): proxies converted to compact JSON
fitted to the hm08 base mesh; textures downsized; hair, brow and lash textures
converted to tintable greyscale; skin textures retouched to remove anatomical
detail; the brown iris desaturated. Leaf coverings are generated in code
(character-human-proxies.js).
